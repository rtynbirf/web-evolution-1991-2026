# КАНОН-ЭКЗАМЕН · исполняемый стандарт автономной HTML-экспозиции

Волна ×3 · добивание (W3-E) · предложение [web-evolution-1991-2026].
Статус канона: **append-only** — новые ступени экзамена добавляются, прежние не удаляются
и не смягчаются. Экспозиция при экзамене только измеряется, никогда не редактируется.

## Зачем

Автономность экспозиции («один файл, ноль внешних запросов») держалась на честном слове
генератора: ни один CI не падал, если в файл вклеивался внешний `<script src="https://…">`.
Канон-Экзамен делает автономность исполняемой проверкой: падение CI — сигнал, а не декларация.

## Три ступени (workflows/exposition-canonical.yml, python-stdlib, ноль зависимостей)

1. **Анти-URL.** Собираются все `src=`, `href=`, `srcset=`, `poster=` (включая самозакрытые
   теги), все `url()` и `@import` в CSS. Валидны только `data:`, `#фрагменты` и относительные
   пути из allowlist конфига. Нарушение = падение CI с точной строкой файла и самим URL.
2. **Size budget.** Файл больше бюджета роняет экзамен с печатью «факт/бюджет».
3. **Скелет.** Непустой `<title>`, `lang` у `<html>`, `<meta charset>`; шрифты — только
   системный стек с фолбэком (внешние `@font-face` ловит ступень 1).

Экзаменатор снабжён самотестом: перед экзаменом он прогоняет синтетический файл с внешней
ссылкой и обязан поймать её с точной строкой — иначе шаг CI краснеет сам.

## Конфиг (контракт для всех экспозиций роя)

Различия между экспозициями — только в `exposition.config.json`, reusable workflow общий.
Шаблон (значения web-evolution-1991-2026, бюджет 300 КБ с запасом к фактическим ~267 КБ):

```json
{
  "exposition": "web-evolution-1991-2026",
  "entry_html": "evolution-web-1991-2026.html",
  "size_budget_kb": 300,
  "allow_relative_prefixes": ["fonts/", "screenshots/", "src/", "tools/"],
  "skeleton": ["title", "lang", "charset", "no-external-fonts"],
  "comment": "Канон-Экзамен · различия экспозиций роя — только в этом конфиге."
}
```

Поля `exposition`, `entry_html`, `size_budget_kb` заполняет владелец каждой экспозиции при
подключении. Без конфига экзаменатор работает на встроенных значениях по умолчанию
(эти же entry/budget/prefixes), так что гейт зелёный и до первого конфига.

## Как подключается братская экспозиция

В репо экспозиции создаётся файл `.github/workflows/exposition-canonical.yml` с вызовом
reusable workflow этого репо (пример, владелец подставляет свои owner/репо/пути):

```yaml
jobs:
  canon:
    uses: rtynbirf/web-evolution-1991-2026/.github/workflows/exposition-canonical.yml@main
    with:
      config_path: exposition.config.json
```

## Границы канона

- Не редактирует экспозицию и не переносит файлы — только измеряет и выносит вердикт.
- Не запрещает относительные ссылки на внутренние файлы репо — их открывает allowlist.
- Не проверяет визуальный APCA-контраст — это зона генерации, а не экзамена.
- Прогон укладывается в секунды: парсер stdlib, сеть не используется.
